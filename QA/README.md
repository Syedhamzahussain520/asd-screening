# Questions and Answers

Questions and answers about the whole research project, written in easy English. Every technical word is explained, with an example where it helps.

Project: Early Autism Screening Using Interpretable Machine Learning Models and a Web-Based Decision Support Tool (COM748, Ulster University).

| File | What it covers |
|---|---|
| 01_project_overview.md | The problem, the aim, the research questions and the main message |
| 02_data.md | The six datasets, the questionnaires, how the label is made, the cleaning |
| 03_methods.md | Leakage, cross-validation, SMOTE, the six models, the tests that were run |
| 04_metrics_and_statistics.md | Every measure and statistical test, with examples |
| 05_results.md | What was found, with the key numbers |
| 06_explainability.md | SHAP, LIME and EBM, and how well they agree |
| 07_web_tool_and_ethics.md | The web tool, privacy, and the rules for medical software |
| 08_supervisor_feedback.md | The ten feedback points and how each was handled |
| 09_limitations_and_future_work.md | Limits, future work, challenges and lessons |
| 10_code_and_notebooks.md | How the code is organised and what each notebook does |
| 11_hard_questions.md | Difficult questions an examiner may ask |
| 12_glossary.md | All short forms and terms with examples |
| 13_research_gap_and_related_work.md | Earlier studies, their weak points and the research gap |
| 14_contributions.md | What is new in this project |
| 15_data_splitting_and_experiments.md | How the data was split and how each experiment was run |
| 16_discussion.md | What the results mean |
| 17_implementation.md | What was done in which file and which function |
